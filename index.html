Whisper Base q8 · 영상/음성을 외부로 보내지 않습니다. 첫 실행에는 이미 포함된 약 102.3MB 모델·엔진을 메모리에 읽습니다. 음성 인식 결과는 수정 가능한 초안입니다. 별도 오디오 트랙은 자동 자막 대상에 포함하지 않습니다.

말소리가 불확실하면 자동 생성을 보류합니다. 긴 영상의 30초 분석 경계와 작은 실제 음성도 보류될 수 있으므로, 듣고 확인한 뒤 선택 클립에서 완화 검사로 재시도하세요. 배경음의 오인식을 완전히 막지는 못합니다.

    CutAssist 사용자 매뉴얼

    가져오기 → 편집 → 자막 검토 → 저장 순서로 시작하세요.

    1. 시작하기

    영상 가져오기를 누르거나 파일을 끌어 놓으세요. 여러 영상을 추가하면 한 트랙에 이어집니다. 작업 영상은 서버에 업로드하지 않습니다. 자동자막 모델 파일은 처음 사용할 때 사이트에서 브라우저로 내려받습니다.

    2. 영상 편집

    클립을 클릭해 선택합니다. 시간 눈금이나 세로 바를 끌어 재생 위치를 정하고 분할하세요. 클립 양끝을 끌면 원본 범위 안에서 길이를 조절합니다. 드래그로 다른 클립의 앞·뒤에 놓으면 순서가 바뀝니다. 삭제하면 뒤 영상이 앞으로 당겨집니다. 전체 보기로 모든 구간을 볼 수 있습니다.

    3. 전환·효과 추천

    영상이 2개 이상일 때 전환·효과 추천을 누르세요. 각 사용 구간의 시작·끝 최대 5초를 비교해 경계별 초안을 만듭니다. 경계의 + 버튼을 눌러 종류·길이·확대를 조정하고 잠글 수 있습니다. 영상 순서나 길이를 바꾸면 다시 추천하세요. 모든 캡컷 효과를 자동으로 사용할 수 있는 기능은 아닙니다.

    4. 오디오·음향효과

    오디오 파일을 가져온 뒤 미디어 목록에서 타임라인으로 끌어 배치하세요. 위치·사용 구간·볼륨을 조절할 수 있습니다. 영상 구간을 삭제하거나 삽입해도 별도 오디오는 기존 시간 위치를 유지하므로 확인하세요. 미리보기 음소거는 MP4 출력 소리를 제거하는 설정이 아닙니다.

    5. 자동자막

    자동자막에서 전체 또는 선택 클립을 검사하세요. 생성한 자막은 초안이므로 잘못된 문구·시간을 직접 수정하고, 음성이 불확실한 구간은 들어서 확인하세요. 자막 블록을 누르면 편집 창이 열립니다. SRT도 저장할 수 있습니다.

    6. JSON 저장·복원

    JSON 내보내기는 편집 설정을 저장하며 원본 영상·오디오는 포함하지 않습니다. 다시 작업할 때 같은 원본 파일을 먼저 추가하고 JSON 불러오기를 누르세요. 작업 복구는 현재 브라우저의 자동 저장 기록을 사용합니다. 브라우저 데이터 삭제나 다른 기기로의 이동을 대신하는 백업은 아닙니다.

    7. MP4 완성 영상 저장

    내보내기 → MP4 영상 저장에서 해상도·프레임률을 정합니다. MP4 만들기를 누르면 지원 브라우저에서 저장 위치·이름을 고릅니다. 지원하지 않으면 다운로드 방식입니다. 이 도구의 컷·디졸브·페이드·확대·자막·오디오를 반영합니다. 캡컷 전용 효과 전체를 렌더링하지는 않습니다. 출력 중에는 탭을 열어 두세요.

    8. 캡컷에서 이어 편집

    내보내기 → 캡컷 프로젝트 저장으로 미디어 포함 폴더 또는 ZIP을 저장합니다. ZIP은 압축을 푸세요. 캡컷을 완전히 종료한 뒤 저장한 프로젝트를 캡컷에 등록에서 저장 폴더와 캡컷 보관 폴더를 연결하고 미리보기를 확인하세요. 등록 후 캡컷을 열면 홈 목록에서 편집할 수 있습니다. 폴더 저장과 홈 목록 등록은 별도 단계입니다. 자막은 별도 SRT로 가져와야 합니다. 전환 종류에 따라 사용자 PC의 전환 리소스 경로가 필요할 수 있습니다. CapCut 9.6에서 검증했으며 다른 버전은 확인이 필요합니다.

    9. 제한·문제 해결

    영상 한 트랙에서 이어 붙이는 편집을 지원합니다. 영상은 최대 100클립, MP4 출력은 30클립·10분·미디어 512MiB 이내입니다. 분할 조각도 각각 셉니다. 실행 취소는 영상·전환 편집 최대 50단계입니다. 미디어 가져오기·JSON 복원·별도 자막 수정 시 이력이 초기화됩니다. 저장 위치 선택과 캡컷 등록은 최신 Chrome/Edge의 HTTPS 환경에서 사용하세요. 잠시 영상 준비 중이 나타나면 프레임 읽기가 끝날 때까지 기다리세요.

    다중선택·색보정·전환 관리

    Ctrl/⌘+클릭으로 추가·해제하고 Shift+클릭으로 범위를 선택합니다. 여기부터 뒤쪽 선택은 활성 클립부터 끝까지 선택합니다. 선택 클립을 드래그하면 상대 순서대로 함께 이동하며 복사·잘라내기·삭제도 묶음 적용합니다. 별도 오디오 위치는 유지합니다. 색보정은 선택 클립에 변경한 항목만 적용합니다. 미리보기와 MP4는 동일한 보정 처리를 사용합니다. 캡컷은 편집 가능한 기본 조정값으로 저장하므로 화면 색감이 다를 수 있고, CapCut 9.6에서는 색보정 자료 경로를 입력하지 않아도 사용할 수 있습니다. 다른 설치 환경에서 필요한 경우 고급 설정에 경로를 지정하세요. 트림은 활성 클립에만 적용합니다. 선택 클립 사이 전환 적용과 선택 사이만 추천은 양쪽 클립 모두 선택된 경계에 한정합니다. 잠긴 전환은 자동 추천에서 제외됩니다. 이 전환 제거/선택 사이 제거/전체 전환 제거는 확대·색보정을 유지하며 실행 취소할 수 있습니다.
